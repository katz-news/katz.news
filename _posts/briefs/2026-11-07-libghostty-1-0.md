The terminal in your IDE is now running on a library you have never heard of. Libghostty 1.0, the C library extracted from the Ghostty terminal, has reached version one — and it is already everywhere.

Mitchell Hashimoto built Ghostty in 2022, and the question he kept hearing was 'why?' The answer is now a list. JetBrains IDEs run on libghostty, putting it in front of some 12.5 million users. Neovim is replacing its old terminal library with it, closing a ten-year-old bug about scrollback on resize. KDE is experimenting with a Konsole replacement on it. Vercel, OrbStack, devenv and a wave of new 'agentic' coding tools use it. More people now use a terminal powered by libghostty than use Ghostty itself.

The 1.0 label is a promise, not a party. The library follows semantic versioning with strict ABI compatibility, so distributions can package it and developers can link against it without fear of breakage. It is MIT licensed, needs nothing beyond libc at runtime, and runs on everything from macOS and Windows to bare-metal RISC-V chips.

Best of all, you can build a terminal with roughly 1,500 lines of C — more features and better performance than nearly any terminal that existed in 2025.

Conclusion: libghostty is not a terminal, but rather the terminal's engine — a quiet, portable piece of plumbing that already powers millions of screens.
