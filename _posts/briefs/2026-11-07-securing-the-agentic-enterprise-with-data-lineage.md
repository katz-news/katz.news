An AI agent just leaked your pricing to a customer. Nobody knows how. That is the scenario MIT Technology Review opens with — and it is the whole point.

A sales representative asks an AI agent for customer pricing. The agent pulls data from restricted pricing systems, internal communications and archived quotes. The output looks accurate, so a second agent drafts the proposal. No human checks either handoff. When the proposal turns out to contain unapproved, confidential and sensitive information, no one can trace where the bad data entered the workflow or how it spread across systems, files and agents.

The argument is that AI governance has to evolve. Enterprises are no longer managing static files; they are managing data that is continuously ingested, copied, summarised, transformed, reused and redistributed. Traditional security — built around applications, systems, networks and endpoints — is no longer enough.

The answer, the piece argues, is data lineage: knowing how data moves, so governance, accountability and trust can follow it across human, agentic and hybrid workflows.

Conclusion: AI security is not a tool problem, but rather a visibility problem — a paper trail, patiently plotted, that follows the data wherever it goes.
