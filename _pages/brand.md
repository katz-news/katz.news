## Logo

The logo stacks three lines: **KATZ** in Orbitron Black, the German name in Fraktur, and the English name in Orbitron Regular. KATZ always spans exactly the width of the German name.

- **Clear space:** at least the height of the Fraktur line on every side.
- **Minimum size:** full lockup 240 px (40 mm); compact 160 px (28 mm); wordmark 80 px (15 mm). Below 64 px, use the monogram.
- **Never** stretch, rotate, recolour outside the palette, add effects, set KATZ in Fraktur or the German name in Orbitron, or pair the logo with memes.

## Typography

| Font | Use |
| --- | --- |
| Orbitron (Black, Regular) | The KATZ wordmark and the English subtitle |
| UnifrakturMaguntia | The German name only |
| Barlow (Regular, SemiBold) | Interface and short texts |
| IBM Plex Mono (Regular, Medium) | Rails, dates, labels and data |
