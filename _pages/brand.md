## Logo

The logo stacks three lines: **KATZ** in Orbitron Black, the German name in Fraktur, and the English name in Orbitron Regular. KATZ always spans exactly the width of the German name.

- **Clear space:** at least the height of the Fraktur line on every side.
- **Minimum size:** full lockup 240 px (40 mm); compact 160 px (28 mm); wordmark 80 px (15 mm). Below 64 px, use the monogram.
- **Never** stretch, rotate, recolour outside the palette, add effects, set KATZ in Fraktur or the German name in Orbitron, or pair the logo with memes.

**To install in Gmail:**

1. Open this page in a desktop browser. Select everything inside one box above, from the logo to the last line, and copy it.
2. In Gmail: **Settings › See all settings › General › Signature › Create new**. Name it, paste, and edit the name, role and address.
3. Under *Signature defaults*, choose it for new emails and for replies, and tick *Insert signature before quoted text*.
4. For a shared address set up under *Send mail as*, choose the shared signature for that address.

Pen names: use the name the person uses with that contact. Virtual Contributors do not send email.
